## Project Description

## Technologies
- HTML
- CSS
- JavaScript
- Supabase PostgreSQL
- Supabase REST API
- GitHub Pages

## Features
- Display tasks
- Add new tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete tasks
- Store tasks in Supabase database
